# Legacy Design System

The existing Bridge Acc design direction is called “Refined Precision.”

## Existing Aesthetic

- Light background
- White cards
- Zinc neutral scale
- Small typography
- Precise B2B SaaS feel
- Minimal accents only for financial meaning

## Strengths

- Trustworthy for accounting workflows
- Easy to read
- Low distraction
- Good fit for German B2B finance use
- Clear semantic colors for income, expense, VAT, and warnings

## Limitations for AI OS Direction

The new BridgeMakers AI OS concept needs a stronger system identity:

- Command center feeling
- AI department roles
- Quest and strategy framing
- Memory and briefing surfaces
- Dark futuristic interface options

## Design Strategy Going Forward

Do not throw away the existing design system. Treat it as the “accounting precision layer.”

Recommended approach:

- Keep finance tables, forms, invoice details, and report exports restrained and precise.
- Use AI OS styling on dashboards, command centers, agent cards, briefing panels, and strategic views.
- Avoid making every accounting screen look like a game interface if it hurts readability.

## UI Direction Bridge

The first transition should use a hybrid:

- Dark shell / command center background
- High-contrast KPI cards
- Existing table and form density
- Neon accents only for status, priority, and AI insights
- No decorative clutter in transaction-heavy screens
