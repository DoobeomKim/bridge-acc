# Bridge Acc / AI OS Documentation

This folder separates the existing accounting product documents from the new BridgeMakers AI Operating System direction.

## Document Areas

- `current-system/`: facts about the existing Bridge Acc accounting system.
- `ai-os/`: official product direction for the AI-powered company operating system.
- `references/`: inspiration, source notes, images, and concept artifacts.

## Working Rule

Personal notes can stay in Apple Notes or external idea folders. Once an idea becomes part of the product direction, promote the distilled version into `ai-os/`.

Existing accounting behavior should be treated as a protected base layer unless a change is explicitly planned in the AI OS roadmap.
