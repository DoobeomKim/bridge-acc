# MVP Scope

## MVP Definition

The MVP is not “AI runs the company.”

The MVP is:

> A CEO command center that shows company state, finance signals, active quests, and AI-generated daily priorities from manually entered memory and existing accounting data.

## MVP Must Include

### 1. Finance Command Center

Use existing Bridge Acc accounting data:

- Income
- Expense
- Net income
- VAT payable
- Recent transactions
- Category breakdown

Reframe the dashboard as a command center rather than a plain accounting dashboard.

### 2. CEO Briefing

A briefing card that summarizes:

- Top 3 priorities
- Revenue-linked action
- Blocked issue
- Recommended decision

MVP can start with rule-based or manually generated content before deeper AI automation.

### 3. Department Agent Cards

Seven role-based cards:

- Production AI
- Planning AI
- Marketing AI
- Finance AI
- Network AI
- R&D AI
- Culture AI

In the MVP, these are not autonomous agents. They are role-based views that show focus, blocker, and next action.

### 4. Quest Board

A simple task/quest model:

- Title
- Department
- Status
- Priority
- Due date
- Next action
- Related note or project

### 5. Quick Add Memory

One simple input for:

- Meeting note
- Idea
- Client update
- Task

MVP can store these as notes first, then later convert them into quests or insights.

### 6. Company Memory

Basic searchable buckets:

- Projects
- Clients
- Lessons
- Decisions

## Explicitly Out of Scope for First MVP

- Full autonomous agents
- Automatic email sending
- Full calendar integration
- Multi-user team collaboration
- Complex permissions
- 3D globe or heavy cinematic interface
- Automatic bank/CRM/project integrations beyond existing finance data
- Rewriting all accounting pages

## MVP Success Criteria

- The current accounting dashboard feels like part of a larger company operating system.
- The CEO can see what matters today within one screen.
- The design direction is clear without harming accounting usability.
- The system creates a natural path from finance data to company action.
