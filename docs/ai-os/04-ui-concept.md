# UI Concept

## Direction

The interface should feel like a clean strategy game command center mixed with a serious business dashboard.

It should be futuristic, but it must not become decoration-heavy or hard to use.

## Visual Keywords

- Command center
- Department agents
- Quest board
- Finance signal
- Company memory
- Strategic briefing
- Dark HUD
- Clean data cards
- Subtle glow
- Practical SaaS density

## MVP Visual Approach

Use the AI OS styling mainly on:

- Dashboard shell
- CEO briefing
- Agent cards
- Quest board
- Memory input
- Strategy room

Keep precision styling on:

- Transaction tables
- Invoice forms
- Quote forms
- Report exports
- Legal/accounting detail views

## Core UI Regions

### Left Sidebar

Brand identity, navigation, system status.

### CEO Briefing

Four short cards:

- Top 3 Priorities
- Revenue-linked Action
- Blocked Issue
- Recommended Decision

### Department Agents

Seven cards with:

- Agent name
- Department role
- Focus
- Blocker
- Next action
- Progress/status

### Active Quest Board

Simple operational list:

- Quest
- Department
- Status
- Next action

### Quick Add Memory

One input area with quick types:

- Meeting Note
- Idea
- Client Update
- Task

### Company Memory

Four buckets:

- Projects
- Clients
- Lessons
- Decisions

## Design Guardrails

- Do not use too much tiny text.
- Do not hide accounting clarity behind sci-fi styling.
- Do not use heavy 3D elements in MVP.
- Do not make forms feel like a game.
- Do not rewrite content before the data and workflow mapping is clear.
