# Information Architecture

## Top-Level Navigation

Initial AI OS navigation should stay close to existing Bridge Acc modules while introducing the new operating-system framing.

Recommended MVP navigation:

- Command
- Finance
- Transactions
- Clients
- Quotes
- Invoices
- Reports
- Memory
- Settings

Later expansion:

- Agents
- Quests
- Strategy Room
- Projects
- Network
- Production
- Marketing

## Current to Future Mapping

| Current Bridge Acc | AI OS Interpretation |
|---|---|
| Dashboard | Finance Command Center |
| Transactions | Transaction Stream |
| Customers | Client Memory |
| Quotes | Proposal Quests |
| Invoices | Revenue Pipeline |
| Reports | Financial Intelligence |
| Settings | Company System Config |

## MVP Screen Hierarchy

### Command

High-level CEO view:

- CEO Briefing
- Finance snapshot
- Active quests
- Department agent cards
- Quick add memory

### Finance

Accounting-focused view:

- Income/expense/net/VAT cards
- Category breakdown
- Recent transactions
- Open invoices
- Payment follow-up prompts

### Memory

Knowledge capture:

- Quick add
- Meeting notes
- Client updates
- Decisions
- Lessons

### Quests

Work management:

- Active
- Blocked
- Due
- Done
- Department filters

## Design Principle

Command screens can feel game-like and futuristic. Accounting detail screens should remain calmer, denser, and precise.
